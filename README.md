# IssueWatch API

IssueWatch API is a Spring Boot backend system for reporting, tracking, assigning, and resolving system downtime or technical issues.

## Tech Stack

- Java 21
- Spring Boot
- Spring Web
- Spring Security
- Spring Data JPA
- MySQL
- JWT Authentication
- Maven
- Docker
- GitHub Actions

## Planned Features

- User registration and login
- JWT access tokens
- Refresh tokens
- Role-based authorization
- Issue reporting
- Issue assignment
- Issue comments
- File attachments
- Email notifications
- Scheduled jobs
- Testing
- Docker deployment
